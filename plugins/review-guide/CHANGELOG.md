# Changelog

Release-please writes this file from the conventional commits merged to `main`. Entries before it took over are summarized below.

## 0.2.0 (2026-10-24)

- The guide is written freely as HTML by an Opus author, with pictures drawn by figure artists in parallel.
- A director picks the reviewers a stack needs; each finding is checked by a verifier.
- Questions from anywhere on the page, answered from the code, with proposed comments, re-judges and guide fixes.
- Self-review of the local branch stack, with the feedback sent back to the implementing session.
- A guide can be shared as one file and imported on another machine.
- One server per machine with an inbox of reviews and rounds.
